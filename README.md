# Kali Beautifier 🧼🎨

> A Bash script to clean, beautify, and optimize your Kali Linux desktop (XFCE). Make your system look modern, feel lighter, and run smoother.

## ✨ Features
- Papirus and Qogir icon & GTK themes
- Plank dock for macOS-style interface
- System cleaning with BleachBit, Czkawka, Stacer
- One-click cache clearing, optimization

## 💻 Install

```bash
git clone https://github.com/zadwen/kali-beautifier.git
cd kali-beautifier
chmod +x kali_beautify.sh
./kali_beautify.sh
```
